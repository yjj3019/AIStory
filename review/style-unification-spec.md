# AIStory → BotStory 스타일 전면 통일 패키지 (2026-10-04)

결정: 사용자 확정 — 해요체 통일 + 장 끝 메타 요약 교체 포함 전면 통일.
실행 전제: 본문 `AIStory.html`·`narration.json`은 사용자 PC에만 있어, 아래 원고는 본문 대조 후 확정함. 검증은 `review/style_check.py`로 기계 판정 (BotStory 본문 통과 실측: 해요체 99.6%, 숫자 0개, 평균 33.1자).

## 1. 변환 규칙 (전 장 공통)

| 항목 | 규칙 |
|---|---|
| 어미 | 전 문장 해요체. 합니다체는 엔딩 `감사합니다` 1문장만. `~죠/~인데요/~고요/~볼게요` 혼합으로 단조로움 해소 |
| 숫자 | 낭독 원고는 아라비아 숫자 0개, 전부 한글 수사. 연도는 4자리 한글, 6월은 `유월`, 10월은 `시월`. 금액·비율도 한글 (`오십억 달러`, `구십 퍼센트`) |
| 문장 | 평균 30-35자 목표. 70자 초과는 분할. 한 문장에 날짜·수치·귀속을 동시에 실지 않음 |
| 질문 | 장당 1개 이하, 전체 3% 이하. 자문자답 연속 배치 금지 |
| 비유·위트 | 장당 최대 1개. 쓰면 바로 다음 문장에 `어디까지나 비유예요` 등 한계 고지 |
| 용어 | 영문 약어·신조어는 첫 등장 때만 `곧 ~` 한 구 풀이. 낭독 발음이 갈리는 고유명사는 SPOKEN 치환으로 확정 후 합성 |
| 장 시작 | 이전 장 회상 또는 시간 이동 한 문장으로 시작 (3종 순환: 회상형/시간 이동형/질문형) |
| 장 끝 | 메타 요약 (`그런데 이것이 ~를 의미한다`) 전면 폐지. 아래 3형을 장마다 바꿔 적용: ① 다음 장 예고 ② 한계·주의 고지 ③ `지금 당신의 손에` (그 장 업적이 오늘 쓰는 AI와 닿는 한 문장) |
| 오프닝 | 인사 → 부정 선언 → 핵심 질문 하나 → `계보`는 비유임을 표지 → 출발점 → 로드맵 → 범위 안내 → 보는 법 안내 (BotStory 8단계) |
| 엔딩 | 오프닝 질문 콜백 → 답 → 비유 콜백 → 청자 질문 1개 → `감사합니다`로만 종결. 새 주장으로 끝내지 않음 |
| 목소리 | BotStory와 동일 보이스 (OmniVoice, 서버 원본 `voice_prompt.pt` 캐시 재사용, `--force`·`--refresh-prompt` 금지). 속도 계열 동일 유지, 분량은 실측 시간으로 판정 |

## 2. 오프닝 초안 (엔딩 콜백과 쌍)

안녕하세요. 오늘은 인공지능의 발명품 이름을 늘어놓지 않으려고 해요. 지금 우리가 매일 쓰는 AI가 어떤 사람들 덕분에 여기까지 왔는지, 그 질문 하나만 따라가 볼게요. 계보라는 말은 이 이야기에서 쓰는 비유예요. 사람들이 만나고 갈라지며 이어진 길이라는 뜻이에요. 출발점은 천구백오십년, 기계가 생각할 수 있느냐는 질문이에요. 다트머스에서 시작해 겨울을 지나고, 알렉스넷과 트랜스포머를 거쳐 지금의 회사들까지 와요. 날짜와 숫자는 확인된 범위에서만 말씀드려요. 사람 이름을 외우기보다, 그 사람이 무엇을 배울 수 있게 만들었는지를 봐 주세요. (분량 안내 문장은 본문 총장 확정 후 삽입)

## 3. 엔딩 초안

오늘은 왜 지금의 AI가 있는지, 그 질문 하나만 따라왔어요. 겨울을 버틴 사람들과 도구를 먼저 만든 사람들, 그리고 가르친 사람들을 봤죠. 처음 질문으로 돌아가 볼까요? 답은 한 사람의 천재성보다, 이어진 사람들의 선택에 있었어요. 계보는 비유일 뿐이에요. 다만 그 길을 따라가면, 지금 손에 든 도구가 공짜로 생기지 않았다는 건 분명해져요. 새 AI를 만날 때마다 물어보세요. 이건 누가, 무엇을 배울 수 있게 만든 결과인가요. 끝까지 함께해 주셔서 감사합니다.

## 4. 장 끝 교체 원고 (18장, 메타 요약 대체)

형식 표기: 예고=다음 장 예고, 한계=주의 고지, 손=지금 당신의 손에.

1. 다트머스 (예고): 질문은 이미 여섯 해 전에 나와 있었어요. 이제 이름을 붙인 사람들이 한자리에 모인 거예요. 다음 장에서는 첫 번째 대답이 왜 겨울을 맞았는지 볼게요.
2. 첫 겨울 · 로젠블랫 (한계): 기대만큼 크지는 않았던 거예요. 다만 씨앗은 남았어요. 겨울이 길어져도, 한 번 배운 건 사라지지 않거든요.
3. 기호주의 몰락 · 연결주의 부활 (예고): 규칙으로 쌓은 탑은 손으로 일일이 올려야 했어요. 그래서 다음 장의 사람들은, 배우는 쪽에 남기로 했어요.
4. 비주류 시절의 세 사람 (손): 겨울에도 자리를 지킨 사람들이 있었어요. 남들이 떠난 연구실에 남은 건, 배우는 기계라는 믿음이었어요.
5. 데이터와 GPU (손): 오늘 사진 검색이 바로 되는 건 우연이 아니에요. 데이터를 설계한 사람과 계산 칩을 만든 사람이 먼저 있었기 때문이에요.
6. AlexNet (한계): 여기서 한 가지만 기억해 주세요. 새 알고리즘만이 아니에요. 데이터와 칩이 한날한시에 만난 거예요.
7. 딥마인드 (한계): 게임에서 이긴 기계가, 다음에는 과학의 문제를 풀기 시작해요. 다만 그 힘이 한 회사 안에 모인다는 건, 또 다른 얘기예요.
8. OpenAI 창립 (예고): 이기고 지는 이야기 뒤에는, 회사를 세운 사람들이 있어요. 나눠 가진다는 약속이 어떻게 흔들리는지, 이어서 볼게요.
9. 트랜스포머 (손): 지금 쓰는 번역과 요약의 출발이 이 구조예요. 여덟 명이 쓴 짧은 논문 하나가 판을 바꾼 셈이에요.
10. 머스크의 이탈 (예고): 약속과 돈이 부딪히면, 사람이 먼저 나뉘어요. 다음 장에서는 남은 사람들이 규모를 키우는 쪽을 택해요.
11. GPT와 스케일링 (한계): 크게 만들면 달라진다는 건, 해 보기 전엔 아무도 몰랐어요. 믿고 밀어붙인 사람들의 얘기가 다음 장이에요.
12. Anthropic (예고): 같은 연구실에서 나온 두 회사가 서로 다른 답을 냈어요. 안전을 먼저 묻는 쪽의 얘기를 들었으니, 이제 세상이 답할 차례예요.
13. ChatGPT (한계): 오늘 우리가 AI 하면 떠올리는 화면이 여기서 나왔어요. 다만 잘나갈 때일수록, 안에서는 다른 일이 벌어지고 있었어요.
14. 해임과 복귀 (손): 닷새 만에 돌아온 건 한 사람만이 아니에요. 그 회사에 건 돈과 신뢰가 같이 돌아온 거예요.
15. 연쇄 이탈 (한계): 사람은 나가도, 배운 건 남아요. 나간 사람들이 각자 회사를 세우면서 계보는 더 넓어졌어요.
16. 구글과 메타 (예고): 먼저 만든 쪽이 늘 먼저 도착하는 건 아니에요. 가진 걸 어떻게 쓰느냐가 다음 장의 지형을 정해요.
17. 지금 (예고): 지도는 아직 그려지는 중이에요. 그래서 마지막 장에서는, 이 계보 밖에 서 있는 사람들을 볼게요.
18. 가계도 밖에서 (질문 콜백): 계보 밖에도 사람들은 있었어요. 칩을 만들고, 다른 나라에서 다른 길을 연 사람들이에요. 처음 질문으로 돌아가 볼까요?

## 5. 실행 순서 (본문 파일 도착 즉시)

1. `AIStory.html` SCENES에 정정 교체문 + 보완 삽입문 반영, 장 끝을 위 4절 원고로 교체, 어미·숫자 전 장 변환
2. `extract_narration.py` 재실행 → `style_check.py`로 해요체 99%·숫자 0개·평균 길이 판정 (미달이면 해당 장만 재변환)
3. `render_tts.py --dry-run`으로 재합성 대상 확정 → rhel-storage에서 서버 캐시 목소리로 증분 재합성 (이 PC 렌더링 금지 규칙 유지)
4. STT 검증 → `audio18/sync.json` 재생성 → `build_slide.py` 슬라이드 재생성 → 브라우저 종단 확인
5. 남은 미검증: Ortet 한글 표기, GAN 낭독 표기 (SPOKEN 치환 확정 후 합성)
