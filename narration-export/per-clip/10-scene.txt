이천십사년, 이안 구드펠로와 공동 연구자들은 적대적 생성 신경망을 제안했어요. 생성기는 데이터를 만들고, 판별기는 실제 자료와 생성된 자료를 구분해요. 두 모델이 주고받는 학습 신호로 생성 결과를 개선하는 방식이에요. 항상 안정적으로 학습되거나 다른 방식보다 빠른 것은 아니에요. 적대적 생성 신경망은 생성 모델의 중요한 한 갈래이고, 지피티의 직접적인 전신은 아니에요. 이천십팔년, 알렉 래드포드와 공동 연구자들은 나중에 지피티 원이라 불린 모델을 발표했어요. 먼저 많은 글에서 다음 토큰을 예측하도록 학습하고, 그다음 특정 과제에 맞춰 조정했어요. 사전 학습 자체가 이때 처음 생긴 것은 아니에요. 기존 사전 학습의 흐름과 트랜스포머 구조를 결합해 여러 언어 과제에 적용한 성과였어요. 이천이십년 톰 브라운을 비롯한 연구진은 천칠백오십억 개 매개변수를 가진 지피티 쓰리를 발표했어요. 매개변수는 학습 과정에서 바뀌는 모델 내부의 수치예요. 연구진은 별도의 가중치 조정 없이 예시를 문맥에 넣는 방식으로 여러 과제를 시험했어요. 규모를 키우며 개선된 결과도 있었지만, 추론의 오류와 편향 같은 한계도 남았어요. 크기만 알면 능력을 다 알 수 있는 것은 아니에요. 생성 모델은 새로운 자료를 만들지만, 사람처럼 뜻을 알고 의도해서 만드는 것과 같다고 단정할 수는 없어요. 적대적 생성 신경망과 언어 모델은 서로 다른 목표와 구조를 갖고 있어요. 이름이 비슷해 보이더라도 어떤 자료로 무엇을 예측하도록 학습했는지 살펴보면 차이가 보여요. 이제 이런 기술을 연구하고 서비스로 제공하는 조직과 사람의 이야기로 넘어갈게요.
